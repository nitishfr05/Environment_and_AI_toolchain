## 📖 About the Project

This repository serves as the foundation for the Flyrank Capstone Project. It establishes an AI-first frontend development environment incorporating modern JavaScript/TypeScript tooling, strict Conventional Commits version control, and contextual AI agent instructions via `CLAUDE.md` and `.cursorrules`.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your system:
- **Node.js (LTS):** `node -v` (>= 20.x, recommended 24.x)
- **Git:** `git --version` (>= 2.40)
- **AI Toolchain:** Claude Code CLI (`claude`) or [Cursor IDE](https://cursor.com/)

### Installation & Local Setup

```bash
# 1. Clone the repository
git clone <repository-url>

# 2. Navigate to the project directory
cd flyrank-assignment-1

# 3. Install project dependencies
npm install

# 4. Start the development server
npm run dev
```

## 🤝 Contribution & Git Workflow

All changes and pull requests must follow the [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) specification:

```bash
# Examples of valid commits:
git commit -m "feat(auth): implement user authentication modal"
git commit -m "fix(nav): correct mobile viewport collapse"
git commit -m "docs: update API endpoints in README"
```

Common prefixes: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `perf:`, `test:`, `chore:`.
